# PythonBasicJarvis
AI Voice Assistant built using Python. It recognizes voice commands, opens websites, searches Google and YouTube, plays music, and answers questions using the Groq AI API. It uses SpeechRecognition and pyttsx3 for voice interaction. This project demonstrates Python programming, automation, and AI integration.


# AI Voice Assistant Using Python 🎙️

A beginner-friendly AI-powered voice assistant built with Python that can recognize voice commands, perform basic web actions and answer general questions using the Groq API.

### Features
- Voice input using SpeechRecognition.
- Voice responses using pyttsx3.
- Open Google and YouTube through voice commands.
- Search Google and YouTube.
- Play random singers' music through YouTube search.
- Answer general questions using an AI language model.
- Handle microphone and API errors.

### Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- Groq API
- Webbrowser
- urllib
- Random

### Learning Outcomes
- Python fundamentals
- If-Else statements and loops
- Functions and exception handling
- External library integration
- API integration
- Voice input and output processing

### Future Improvements
- GUI integration
- Improved speech recognition
- Wake-word detection
- Additional automation features
